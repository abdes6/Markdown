# Markdown 笔记应用 · 设计文档

- 日期：2026-08-20
- 状态：已确认

## 1. 概述

本地 Markdown 笔记桌面应用。笔记以纯 `.md` 文件存储于用户选择的文件夹（笔记库 Vault），提供编辑、实时预览、多笔记管理（目录/标签/搜索）、双链与反向链接、导入导出功能。

## 2. 技术栈

- **Tauri 2 + React + TypeScript + Vite**
- 编辑器：CodeMirror 6（Obsidian 同款，Markdown 语法高亮与编辑体验成熟）
- Markdown 渲染：unified / remark / rehype（AST 一次遍历同时完成渲染与索引解析）
- 状态管理：Zustand
- 文件监听：Tauri fs 插件 watch API（Rust 侧监听，事件推送前端）
- 测试：Vitest + Testing Library（前端）、cargo test（Rust）

## 3. 架构

分层职责明确：

- **前端（React，承载绝大部分业务逻辑）**：UI、编辑、预览渲染、索引构建、搜索、双链解析、文件监听、HTML 导出
- **Rust 后端（薄层）**：仅提供文件系统命令——选择笔记库目录、递归列出文件、读写文件、创建/重命名/删除文件、PDF 导出（Webview 打印）、ZIP 打包

## 4. 数据模型

- 笔记库 = 用户选定的任意本地文件夹，每篇笔记一个 `.md` 文件
- 库内隐藏目录 `.mdnotes/` 存放：`config.json`（主题、排序、最近打开状态）+ `index.json`（索引缓存）
- 每篇笔记支持 YAML frontmatter：`title` / `tags` / `aliases`

### 双链与标签语法

- 链接：`[[笔记名]]`、`[[笔记名|显示文字]]`（按文件名与 `aliases` 匹配）
- 标签：行内 `#tag` 或 frontmatter `tags`
- 反向链接 = 全库扫描 `[[...]]` 指向当前笔记的集合

## 5. 界面布局（三栏）

- 左栏：文件树 + 标签列表 + 搜索框（Tab 切换）
- 中栏：CodeMirror 编辑器
- 右栏：实时预览 / 反向链接面板（Tab 切换，可折叠）

## 6. 索引、文件监听与保存

- 打开笔记库时全量扫描：递归读所有 `.md`，解析 frontmatter、提取 `[[链接]]`、`#标签`、标题、字数、修改时间，构建内存索引
- 索引缓存写入 `.mdnotes/index.json`，下次打开先加载缓存再后台校验增量，减少大库启动等待
- 前端用 Tauri fs 插件 watch API（`recursive` + 防抖）监听整个笔记库目录，新增/修改/删除/重命名 → 增量更新索引 → 刷新 UI（外部改动自动同步）
- 编辑器输入防抖 500ms 自动保存 + `Ctrl+S` 强制保存；保存失败保留本地草稿并 toast 提示

## 7. 搜索

- 基于内存索引匹配标题 + 正文（简单子串匹配，个人规模够用）
- 结果按「标题命中 > 正文命中」排序，点击跳转打开对应笔记

## 8. 导入导出

- 导入：选择单个/多个 `.md` 文件或整个文件夹，复制进笔记库，同名自动追加 `-1`/`-2` 后缀，导入后刷新索引
- 导出：当前笔记 → 内嵌样式单文件 HTML；当前笔记 → PDF（Webview 打印）；整个笔记库 → ZIP 打包（Rust 侧 `zip` crate，保留目录结构，排除 `.mdnotes/`）

## 9. 错误处理

- 文件读写失败、权限不足、磁盘满 → toast 通知 + 状态栏提示，不崩溃
- 自动保存失败：保留编辑器内未保存草稿，提示用户手动复制或重试
- 打开中的文件被外部删除/修改 → 提示「文件已被外部修改/删除」，给出重新加载或关闭选项

## 10. 测试

- 单元测试（Vitest）：链接解析、frontmatter 解析、索引构建、搜索排序、文件名冲突策略
- 组件测试（Vitest + Testing Library）：文件树、标签筛选、反向链接面板渲染
- Rust 集成测试（cargo test）：文件读写命令、ZIP 打包
- 端到端手动验证清单：打开库、编辑保存、双链跳转、外部改动同步

5. 索引构建 + 搜索 + 标签

## 12. 明确不做（非目标）

- 不做知识图谱可视化（仅反向链接面板）
- 不做云同步 / WebDAV / 内置 Git 同步（用户自用外部工具同步文件）
- 不做 AI 辅助写作
- 不做协作 / 多用户
